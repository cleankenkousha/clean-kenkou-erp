## 3. 次回やるべき残課題・未対応

### 優先度：高

1. **実現場写真を用いたAI重量推定（kg）の現場フィーリング確認**
   * 木くずの山や粗大ゴミ等の実際の現場写真で「✨ AI自動抽出」を実行し、AIが推定する重量（例: 80kg、150kg等）が現場作業員の感覚と概ね合致しているか検証する。
   * 乖離が大きい場合はプロンプトの推定基準（体積・袋数あたりの想定kg）を微調整する。
2. **タブレット実機でのカメラ起動確認**
   * `netlify.toml` の `Permissions-Policy = "camera=()"` の影響がないか、現場タブレットの「撮影」ボタンから直接カメラが起動するか実機確認する（起動しない場合は `camera=(self)` へ変更）。
3. **Edge Function の利用制限・セキュリティ保護**
   * 現在 `verify_jwt: false` のため、URLを知っていれば呼び出せる状態。ログイン認証済みユーザーのみが実行できるようJWT検証またはトークン検証の導入を検討。

1. **Gemini 2.5 系の廃止対応**
