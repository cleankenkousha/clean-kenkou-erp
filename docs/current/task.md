### 1-7. AI見積もりの再現性向上・同一写真判定ブレの解消（v1.1.4）【完了】

* **課題**: 同じ現場写真群（10枚等）を判定させるたびに見積金額や検出品目が変動する現象が発生。
* **原因分析**:
  1. `generationConfig` の `temperature` が未指定（デフォルト1.0）だったため、トークンサンプリング時に毎回ランダムな推論が走り、推定重量や品目リストがブレていた。
  2. 複数枚（最大10枚）の写真において、同一の不用品（同じ木くずの山や大型家具など）が別アングルから写っている際の重複排除ルールが不足していた。
* **対応**:
  1. **設計書の先行反映**: `docs/06_AI_Design_Guide.md` に 2.5節「見積結果の再現性・決定論的算定ルール」を新設。`temperature: 0.1` の決定論的モード固定、写真間重複排除の原則を明文化。
  2. **Edge Function 改修**: `supabase/functions/gemini-analyze/index.ts` の `generationConfig` に `temperature: 0.1` を追加。プロンプトに「複数枚写真における重複排除・現場全体の一元算定」「再現性のある客観的算定」を最重要項目として厳格指示。
  3. **デプロイ**: `deploy_edge_function` で Supabase クラウド環境（Version 8）へデプロイ完了。
  4. **バージョン更新**: `src/version.ts`, `package.json`, `public/sw.js` を `v1.1.4`（2026.10.07-11:15）へ更新。

### 1-8. 実現場シチュエーション写真を用いたAI重量推定（kg）の現場フィーリング検証【完了】

* **検証内容**:
  * 実稼働中の Supabase Edge Function（Version 8）に対し、リアルな現場写真（廃木材山積み、和室粗大ごみ山積み、家電混在現場、およびユーザー様ご提供の実遺品整理写真）を入力し、AIの推定重量（kg）および特定品目（台・点）の分離精度を検証。
* **検証結果**:
  1. **Case 1（解体廃木材の山積み）**: 「木くず 150kg (40円/kg, 小計¥6,000)」として判定。腰〜胸高の山積みに対し約150kg（軽トラ半載程度）と現場感覚に合致。
  2. **Case 2（室内粗大ごみ・ゴミ袋群）**: 「可燃性粗大ごみ 120kg (45円/kg)」「雑ゴミ 40kg (45円/kg)」「プラスチック類 15〜25kg (85円/kg)」として判定。ゴミ袋数袋(40kg)＋布団・衣装ケース・ダンボール(120kg)で合計約180kgと整合的。
  3. **Case 3（家電混在現場）**: 「大型冷蔵庫 1台」「洗濯機 1台」は単価マスタ通り台単位で個別計上し、併設された「木くず 150kg」「可燃粗大 80kg」「雑ゴミ 60kg」をkg単位で正確に分離判定。
  4. **Case 4（実現場写真：遺品整理・和室）**: 
     * 現行マスタでは「エアコン 1台 (¥12,500)」「雑ゴミ 50kg (¥2,250)」として集約。
     * マスタに「仏壇」「電子レンジ」「座卓」「収納家具」を追加した検証では、**「仏壇（大型） 1基」「電子レンジ 1台」「座卓 1台」「タンス・収納棚 2点」「エアコン 1台」「雑ゴミ 30kg」と全品目を驚くべき精度で完全特定**。
     * **重要知見**: AIの画像認識自体は完璧であり、現場マスタ（`price_master`）に遺品整理向け家具・小型家電（仏壇・座卓・電子レンジ・タンス等）を登録するか、プロンプトでマスタ未登録品目も個別検出させることで、遺品整理現場の自動見積もり精度が劇的に向上することが判明。
* **評価**: 点数制への誤認識は一切発生せず、重量制（kg単価）と点数制（特定家電・家具）が完全に両立して稼働していることを確認。詳細はアーティファクト `ai_weight_estimation_verification.md` に記録。

### 1-12. 最大20枚写真並列解析・複数部屋重複制御・大括り化防止（Version 10 & v1.1.6）【完了】

* **課題**: 写真枚数が10枚以上に増えた際に、以下の3重の要因で認識精度が甘くなる現象が発生：
  1. `imageUrls.slice(0, 10)` による11枚目以降の切り捨て。
  2. プロンプトの重複排除指示が過剰に働き、別の部屋にある別の家具・家電まで「重複」とみなして削ってしまう。
  3. 大量写真によるマルチモーダルAIのアテンション希釈により、特定品目が「雑ゴミ」に大括り化されてしまう。
* **対応**:
  1. **枚数上限拡張**: `src/lib/gemini.ts` および `supabase/functions/gemini-analyze/index.ts` の最大枚数制限を `10` から `20` へ倍増。
  2. **複数部屋エリア認識と重複制御**: プロンプトに「写真は同一部屋の別アングルだけでなく、和室・洋室・台所・廊下・玄関・庭など異なる部屋の写真を含む」ことを明記。同一部屋の同一物品は1つに統合し、別部屋の物品（和室の座卓と台所の机、各部屋のタンスやエアコン等）は絶対に重複とみなさず独立計上するよう厳格指示。
  3. **大量写真の大括り化防止**: 写真枚数が多い場合でも、各写真（1〜20枚目）の隅々に写っている個別特定品目を1枚ずつ丁寧に拾い上げるよう指示。
  4. **デプロイ**: `deploy_edge_function` で Supabase クラウド環境（Version 10）へデプロイ完了。
  5. **バージョン更新**: `v1.1.6`（2026.10.12-15:40）へ更新。
