## 📅 本日の実施内容・進捗 (2026-08-10)

### 1. 多角的な品目単位（kg / 個 / 本 / 台 / 枚 / m3 / 箱 / 袋）の全面対応
- [x] **単位属性 (`unit`) の型定義および計算ロジック統合**
  - `QuoteItem` および `GeminiDetectedItem` に単位フィールドを完全統合。
  - 見積明細行に「単位選択ドロップダウン」を配置し、数量・単価・単位の自由な組み合わせ計算に対応。

### 2. 特定品目（テレビ・リサイクル家電・タイヤ等）のAI認識高精度化 (`gemini.ts`)
- [x] **Gemini API プロンプトの細質化と特定品目の認識指示強化**
  - 液晶テレビ/大型/ブラウン管、冷蔵庫、洗濯機、エアコン、ソファ、ベッド、タイヤ（本）、物干し竿（本）、古紙・金属（kg）などの識別精度を格段に向上。
- [x] **AI検出結果バナーの視覚的ブラッシュアップ**
  - 検出品目に合わせて絵文字アイコン（📺 テレビ, 🧊 冷蔵庫, 🧺 洗濯機, 📦 段ボール, 🛞 タイヤ, ⚙️ 金属等）と単位付きアイテムタグを直感的に表示。

### 3. 社内単価マスタ (`price_master`) 100%自動適用・名寄せ機能 (`matchMasterItem`)
- [x] **マスタ照合ロジックの構築と手動打ち直しの完全撤廃**
  - AIが検出した品目を自社の登録単価マスタと自動同定・照合。
  - 自社で登録した正式品名・設定単価・単位・体積を100%優先セットし、見積入力時の手動打ち直し作業をゼロ化。
- [x] **新規品目追加時のデフォルト設定連動**
  - 手動で品目を追加した際も、自社単価マスタの設定値が初期プリセットされるよう改修。

### 4. 単位区分に応じた体積(m3)計算バグの修正 (`calcItemVolume`)
- [x] **`kg` 単位等の体積誤計算の解消**
  - `kg` 単位（例: 木くず 500kg）の場合、体積入力値を「品目全体の概算体積m3」として扱い、数量500が掛け算されて 500m3 になる異常を修正。
  - `m3` 単位および個数系単位（`台`, `個`, `点`等）の体積計算式を現場実態に合わせて分離適正化。
