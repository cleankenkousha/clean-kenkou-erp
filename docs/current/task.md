**ステータス**:
作業費（現場搬出・作業料）を現場の総体積（総㎥）に対して自動加算する計算式（作業費 = 総㎥ × 社内単価マスタ¥1,500/㎥）を導入。モバイル見積画面（MobileQuoteModal）および見積書印刷（PrintQuoteArea / QuotePrintModal）にて「搬出作業費: +¥○○○ (総 ○○m³ × ¥1,500)」と計算根拠を明示。設計書（03_Business_Rules_Book.md）と整合性を保持し本番デプロイ（v1.1.7）完了。

## 3. 次回やるべき残課題・未対応

### 優先度：高（最重要課題）

1. **同一部屋・複数アングル撮影時における特定品目（テレビ、座卓等）の重複カウント抑制**
   * **現状の課題（現場フィードバック）**:
     * 判定を厳しく（見落とし防止・別部屋の独立計上）した結果、同一の部屋を別アングルから撮影した複数枚の写真において、**同一のテレビを2台、同一の座卓を複数台として重複カウント（過剰計上）してしまう現象**が判明。
   * **対策方針**:
     * プロンプトにおける「同一部屋判定ロジック」の強化: 背景・壁の色・床材・周囲の固定設置物から同一部屋と認識させ、同一特徴（サイズ・形状・色・配置場所）を持つ大型家電・家具が別アングルから写っている場合は1台に統合するよう、重複判定の精度バランスを微調整。
     * 同一空間内の定置物（テレビ台の上のテレビ、和室中央の座卓等）に関する「空間一意性」ルールの導入。
2. **Edge Function の利用制限・セキュリティ保護**
   * 現在 `verify_jwt: false` のため、URLを知っていれば呼び出せる状態。ログイン認証済みユーザーのみが実行できるようJWT検証またはトークン検証の導入を検討。
