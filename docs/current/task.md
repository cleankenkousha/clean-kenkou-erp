## 2. 次回以降の残課題・今後の実装計画

### 🚨【最重要課題・最優先（Priority 1）】AndroidタブレットでのPWA「インストールしています」フリーズ問題の完全究明・解消
- **現象**:
  - Android Chromeにて「アプリをインストール」を実行した際、「インストールしています」の表示（通知プログレスバー）が出たまま止まり、ホーム画面にアプリアイコンが設置されない。
- **検証・アプローチ方針**:
  1. **Google WebAPK生成・Playストアキューのスタック検証**:
     - Android Chromeの「アプリインストール」は裏でGoogleのWebAPKサーバー（`webapk.googleapis.com`）およびGoogle PlayストアのPackage Installerを経由する。
     - 端末側のPlayストアで別アプリの更新が「待機中」になっていないか、Play開発者サービスのキャッシュ詰まりがないかを端末側で点検。
  2. **端末・ホーム画面の設定制限の確認**:
     - 「ホーム画面のレイアウトをロック」がONになっていてアイコン配置がブロックされていないか。
     - Chromeアプリに対する「ホーム画面へのショートカット/アイコン追加」権限が許可されているか。
  3. **PWAパイプラインのさらなる堅牢化**:
     - `vite-plugin-pwa`（Workbox）の正式導入によるキャッシュマニフェスト完全自動生成。
     - Chrome DevToolsのリモートデバッグ（USB/Wi-Fi接続）によるWebAPK生成エラーコード（Lighthouse PWA監査）の詳細ログ取得・分析。
     - もしWebAPK方式が特定端末でスタックし続ける場合の、アドレスバー非表示フルスクリーン確実起動の代替ソリューション（TWA: Trusted Web Activity や APK化など）の検討・準備。
